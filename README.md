# 애정말딸 (각질/거리별) v1.0.0

우마무스메 캐릭터를 거리와 각질별 20칸에 한 명씩 배치하는 오프라인 웹사이트입니다.

## 실행 방법

1. ZIP 파일을 압축 해제합니다.
2. 압축을 푼 폴더의 `index.html`을 더블클릭합니다.
3. `캐릭터 파일 불러오기`에서 기존 나무위키 다운로더가 만든 ZIP을 선택합니다.
4. 아래 캐릭터 목록에서 이미지를 끌어 원하는 칸에 놓습니다.

## 배치표

| 거리 \ 각질 | 도주 | 선행 | 선입 | 추입 |
|---|---|---|---|---|
| 단거리 | 1명 | 1명 | 1명 | 1명 |
| 마일 | 1명 | 1명 | 1명 | 1명 |
| 중거리 | 1명 | 1명 | 1명 | 1명 |
| 장거리 | 1명 | 1명 | 1명 | 1명 |
| 더트 | 1명 | 1명 | 1명 | 1명 |

총 20명을 선택할 수 있습니다.

## 사용 방법

- PC: 캐릭터 카드를 끌어서 칸에 놓습니다.
- 휴대폰 또는 클릭 방식: 캐릭터를 한 번 누르고 원하는 칸을 누릅니다.
- 칸의 `×` 버튼: 해당 칸의 배치를 해제합니다.
- 배치표의 캐릭터를 아래 `배치 해제 영역`으로 끌면 목록으로 돌아갑니다.
- `결과 PNG 저장`: 현재 표를 이미지로 저장합니다.
- `결과 JSON 저장`: 배치 결과를 데이터 파일로 저장합니다.
- `배치 초기화`: 캐릭터 파일은 유지하고 20칸만 비웁니다.

## 캐릭터 불러오기

### 권장 방식
이전에 만든 나무위키 다운로더의 ZIP 파일을 그대로 선택합니다.

ZIP 안에는 다음 파일이 있어야 합니다.

```text
characters.json
images/
  캐릭터 이미지.webp
  캐릭터 이미지.png
  ...
```

WebP, PNG, JPG, GIF, AVIF 이미지를 지원합니다.

### 따로 불러오기
압축을 풀었다면 `characters.json`과 `images` 폴더를 각각 선택한 뒤
`선택한 파일 불러오기`를 누릅니다.

## 새 캐릭터 직접 추가

페이지 아래의 `새 캐릭터 직접 추가`에서 캐릭터 이름과 사진을 선택합니다.
직접 추가한 캐릭터에는 휴지통 버튼이 표시됩니다.

## 저장 위치

캐릭터 이미지와 목록은 브라우저의 IndexedDB에 저장되고,
배치 정보는 Local Storage에 저장됩니다.

따라서 같은 브라우저에서 다시 열면 그대로 유지됩니다.
브라우저 데이터 삭제, 시크릿 모드 종료, 다른 브라우저 사용 시에는 유지되지 않을 수 있습니다.

## 파일 설명

- `index.html`: 사이트 실행 파일
- `style.css`: 화면 디자인
- `app.js`: 드래그, 파일 불러오기, 저장 기능
- `jszip.min.js`: ZIP 파일 읽기 라이브러리
- `JSZIP_LICENSE.md`: JSZip 라이선스
